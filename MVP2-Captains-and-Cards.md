# MVP2 — Captains and Cards (playable 45–60 min)

**Goal:** prove Hand Management + ship identity. Same dice core as MVP1, full Tide deck, basic Favor.
**Requires:** MVP1 rules. Changes below replace MVP1 where noted.

## What is NEW / still OUT

- NEW: all 60 Tide cards (15 types x4), different hand sizes + flagships, Pray action + Favor-reroll only, Old Wyk + Orkmont, 3 more lands (9 total).
- OUT: Faction cards, Storm Belt rolls, Burned/Pillage/Repair, Bounty/Wrath, finale bonuses.

## Components delta

- Cards: full Tide set from `cards.json` / `cards-print.pdf` (Boarding Party through War Horn). Deal to new hand sizes: Euron 5, Victarion 4, Asha 6.
- Ships (now asymmetric):
  - *Silence* (Euron): Move 3, defenders -1 die on first raid vs Euron per Season.
  - *Iron Victory* (Victarion): Carry 6, Move 1 if carrying 5–6.
  - *Black Wind* (Asha): Move 2, may Raid + Sail same turn.
  - 3rd ship back in (3 per player).
- Map: add Old Wyk (control = +1 Legend at season end), Orkmont (+2 Hoard), + Bear Island (D4/4+1), Banefort (D3/3+1), Flint's Finger (D3/3+1). Total 9 lands.
- Favor: 0–7 track, 1 token each. **Only use:** discard 1 card via Pray → +1 Favor; spend 2 Favor → re-roll any dice. Ignore 4/6 miracles until MVP3.

## Setup changes

- Start crew: Euron 6, Victarion 8, Asha 8. Start Hoard 5. Draw to new hand sizes.
- Seasons: **4 Seasons** x 3 Turns x 2 Actions. New 4th action: **Pray** (discard 1 → +1 Favor).
- Season end: draw to hand size, score +1 Legend per Isle controlled (most crew; tie = most ships), most Hoard → +2 Legend. Old Wyk holder +1 Favor, Orkmont holder +2 Hoard. No Wrath yet.

## Playtest questions

1. Does Asha (6 cards) win on card velocity without dominating dice? (If she stalls → allow free retreat, already in.)
2. Is Victarion (4 cards) still fun, or starved? (If starved → let Great Wyk Muster cost 2.)
3. Do players spend Favor or hoard it? (If hoarded → Favor is too weak; keep for MVP3 miracles.)

**Next:** MVP3 adds Faction cards + Storm + Burned + catch-up.
