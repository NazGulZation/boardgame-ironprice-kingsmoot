# IRON PRICE: Kingsmoot — Print & Play

1v1v1 Ironborn board game (Euron vs Victarion vs Asha).

## Files
- `How-to-Play.md` — full rules source
- `How-to-Play.pdf` — printable rulebook (includes map page)
- `cards.json` — 90 cards data (60 Tide + 30 Faction), dice definition
- `cards-print.pdf` — 90 cards, 9-per-page, cut to 63x88mm. Print at 100%.
- `map.json` — 22 nodes + 27 edges, defense/loot values
- `map.png` — 1920x1080 schematic map. Print A3.
- `generate_all.py` — regenerate everything: `python generate_all.py`

## Quick start
1. Print map + cards, grab 18 d6 (6=Kraken, 4-5=Axe, 3=Shield, 1=Eye, 2=miss).
2. Read How-to-Play Setup (5 min).
3. Learning game: 3 Seasons, ignore Storm Belt + 4/6 Favor miracles.
